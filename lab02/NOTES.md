## Рабочая директория

Рабочая директория содержит файлы проекта, расположенные на компьютере. Именно в этих файлах выполняются изменения во время работы над проектом.

## Индекс

Индекс используется для подготовки изменений перед их сохранением в истории Git. С помощью команды git add нужные изменения из рабочей директории добавляются в индекс.

## Коммит

Коммит представляет собой зафиксированную версию подготовленных изменений. Каждый коммит сохраняется в истории репозитория, поэтому при необходимости можно посмотреть или восстановить предыдущие состояния проекта.
