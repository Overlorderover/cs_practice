## Рабочая директория

Рабочая директория содержит файлы проекта, расположенные на компьютере. Именно в этих файлах выполняются изменения во время работы над проектом.

## Индекс

Индекс используется для подготовки изменений перед их сохранением в истории Git. С помощью команды git add нужные изменения из рабочей директории добавляются в индекс.

## Коммит

Коммит представляет собой зафиксированную версию подготовленных изменений. Каждый коммит сохраняется в истории репозитория, поэтому при необходимости можно посмотреть или восстановить предыдущие состояния проекта.

## Git и GitHub

Git предназначен для контроля версий и позволяет отслеживать изменения проекта в локальном репозитории.

GitHub используется для размещения Git-репозиториев в интернете. Благодаря этому можно хранить проект удалённо и обмениваться изменениями с другими компьютерами или пользователями.

Команда git commit фиксирует подготовленные изменения в локальном репозитории. Команда git push передаёт созданные коммиты в удалённый репозиторий на GitHub.

## Команды git diff и git diff --staged

git diff позволяет увидеть изменения, которые были сделаны в рабочей директории, но ещё не добавлены в индекс.

git diff --staged отображает изменения, находящиеся в индексе. То есть с помощью этой команды можно проверить содержимое изменений, подготовленных для создания следующего коммита.
